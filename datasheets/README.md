Ogni file include il percorso locale nel repository e il link pubblico ufficiale per il download diretto o la consultazione online.

## Note per il Laboratorio di Assistenza:
1. **Punti di Test (TP)**: Consultare gli schemi elettrici di ciascun manuale per localizzare `TP1` e `TP2` (uscite amplificatore differenziale di lettura) per il collegamento delle sonde oscilloscopio `J8`.
2. **Tabella Ponticelli**: Prima di collaudare un drive a banco, verificare sempre i jumper `DS0`/`DS1`, `Terminator` e la selezione `Pin 34 (READY vs DISK CHANGE)` sul manuale del rispettivo modello.
3. **Calibrazione Velocità**: Per i drive con motore a cinghia, la posizione del trimmer di regolazione (es. `R4` su Tandon, `VR1` su TEAC) è indicata nelle tavole di manutenzione allegate.
